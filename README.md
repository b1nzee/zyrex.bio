# Zyrex.Bio
> ℹ️ This application is still under development, this document will be updated when the final release is built.

> [!NOTE]  
> This is an open-source NodeJS web application built using Next.JS, this web application allows online users to create their own personal web page as an extended bio. Each user has a unique link to paste into their limited bio on social media platforms such as Discord and X.

> [!NOTE]
> **AI Declaration:** Claude AI is used for designing the frontend of this project using TailwindCSS. Claude AI is not used for important code such as backend and database, ensuring security is properly enforced by a human.
